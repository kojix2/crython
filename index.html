    crython

    :gem: :snake:　 Crystal meets Python!

    Installation

    • A Python interpreter is required as a dependency.
    • Ensure python3-config --ldflags works.
    dependencies:
  crython:
    github: kojix2/crython

    Usage

    require "crython"

    See examples folder. Use make examples to build all examples.

    Development

    Some constants and functions in Python's C API are provided as preprocessor macros. To make them easier to use, Crython uses a small static library (see src/ext/crython.c) that turns them into a fixed C API.
